DROP PROJECT SCREENSHOTS HERE
=============================

1. Save a screenshot or cover image of each project in this folder.
   Suggested names:
     deepdetect.jpg
     universal-shop-management-system.jpg
     saas-billing-engine.jpg
     flutter-chat-app.jpg
     gym-management-system.jpg
     library-management-system.jpg
     online-classroom-management.jpg

2. Open src/data/projects.js and add an `image` line to that project:

      image: "/projects/deepdetect.jpg",

   (each project already has a commented `// image:` line — just
   uncomment it and fix the filename)

Tips
----
- Wide shots work best: aim for ~1600x1000 px or a similar 16:10 ratio.
- JPG or PNG or WebP all work; JPG/WebP keeps the site fast.
- The card crops with object-fit: cover, so exact sizes don't matter.
- Until an image exists, the site shows a clean numbered placeholder
  block instead — the layout never breaks.
